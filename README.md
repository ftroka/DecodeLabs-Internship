## Project 2 — Expense Tracker

### Description

A simple financial tracking application that allows users to record expenses and calculate their total spending.

### Features

* Add multiple expenses
* Continuous expense recording
* Automatic total calculation
* Input validation using try/except
* Prevention of negative values
* User-friendly interaction

### Skills Demonstrated

* While Loops
* Variables
* User Input Handling
* Exception Handling
* Numeric Data Processing
* Conditional Logic

### Sample Output

```text
Enter an expense (or type 'done' to finish): 50
Enter an expense (or type 'done' to finish): 25.5
Enter an expense (or type 'done' to finish): done

Total Spent: 75.50
```

# How to Run

### Clone the Repository

```bash

```

### Navigate to the Project

```bash
cd DecodeLabs-Internship
```

Example:

```bash

```

Make sure Python 3 is installed on your system before running the applications.
